# 📚 Algoritmos Aula

Repositório com anotações e exercícios desenvolvidos durante a disciplina de **Algoritmos**, utilizando as linguagens C e C++.

---

## 🚀 Sobre o repositório

Este repositório reúne materiais produzidos ao longo da matéria, incluindo:

* 📝 Anotações de aula
* 📋 Exercícios práticos
* 🔁 Resoluções de atividades

O objetivo principal é registrar a evolução no aprendizado de lógica de programação e fundamentos de algoritmos.
